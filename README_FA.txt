NEXORA Android source

این مخزن شامل نسخه وب سرگرمی NEXORA و پوسته اندرویدی WebView است.
قابلیت‌های فعلی شامل بازی‌ها و سرگرمی‌های محلی، امتیاز، سطح، مأموریت روزانه، نشان‌ها، پروفایل و تم روشن/تیره است. ذخیره‌سازی فعلی عمدتاً روی همان دستگاه انجام می‌شود.

ساخت APK:
- workflow گیت‌هاب با هر push روی main اجرا می‌شود.
- پس از پایان موفق، فایل NEXORA-debug-apk را از بخش Actions > آخرین اجرای Build NEXORA APK > Artifacts دریافت کنید.
- برای ساخت دستی: JDK 17، Gradle 8.7 و Android SDK Platform 35 لازم است؛ دستور: gradle assembleDebug

محدودیت‌ها:
این نسخه یک نمونه سرگرمی محلی است، نه سرویس ابری یا بازی چندنفره. حساب کاربری آنلاین، همگام‌سازی ابری و هوش مصنوعی واقعی هنوز پیاده‌سازی نشده‌اند. APK تا زمان موفق شدن workflow و آزمایش روی دستگاه، تأییدشده محسوب نمی‌شود.
